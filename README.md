# Faglier's Mixed Martial Arts — Website

Single-page website for **Faglier's Mixed Martial Arts** (Augusta, GA / the CSRA).
Plain HTML + [Tailwind CSS](https://tailwindcss.com) (compiled to a static stylesheet) + a
little vanilla JS. Built for **GitHub Pages**, deployed automatically by GitHub Actions.

## Files

```
index.html                    The entire site (one page, scroll sections)
src/input.css                 Tailwind entry + custom CSS (source for the build)
tailwind.config.js            Tailwind theme (brand green #6CBD45, fonts)
package.json                  Build scripts + Tailwind dev dependency
assets/tailwind.css           COMPILED output — generated by the build (git-ignored)
images/                       Logo + favicons + OG image
robots.txt / sitemap.xml      SEO
llms.txt                      Plain-text summary for AI/answer engines
.github/workflows/deploy.yml  CI: build Tailwind + deploy to GitHub Pages
README.md                     This file
```

## Local development

Requires [Node.js](https://nodejs.org) (v20+).

```bash
npm install        # one-time: installs Tailwind
npm run build:css  # compile assets/tailwind.css once
npm run watch:css  # or: rebuild on every change while editing
```

Then open `index.html` (or serve the folder, e.g. `python3 -m http.server`).

> `assets/tailwind.css` is **git-ignored** — it's a build artifact. The site is unstyled
> until you build it locally; in production GitHub Actions builds it fresh on every deploy.

## Brand &amp; design

Modern, clean, editorial — deliberately distinct from the sibling Backyard Bullies site.

- **Palette:** warm light "paper" base (`#FAFAF6`) with a near-black ink (`#14160F`) and a
  single brand-green accent (`#6CBD45`; `brand.deep` `#2F6A1E` is the contrast-safe green for
  text on light). One dramatic dark band (the Wellmaker section).
- **Fonts:** Archivo (heavy display/headings) + Inter (body).
- **Layout:** full-bleed photo hero, a discipline marquee, a numbered discipline index,
  alternating image/text program rows, clean tables and a dark contact card.
- **Accessibility:** skip link, semantic landmarks, ARIA on the menu/map, visible focus rings
  (bright-green ring on dark bands), reduced-motion handling, contrast-safe color usage.
- Logo art lives at `images/logo.jpg`.
